# Code of conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and constructive. Criticise code and ideas, not people.
- No harassment, discrimination or personal attacks, in any language.
- Assume good faith and keep discussions on topic.

The maintainer may edit or remove comments, issues and contributions that break these rules, and may block
repeat offenders. Report problems privately to the maintainer at **ilpachi@ilpachi.it**.
